# standard_problem_1

## 1) Purpose of the Example

This example implements the **µMAG Standard Problem #1**, testing the interplay of magnetostatic, exchange, uniaxial anisotropy, and Zeeman energies during full hysteresis loops of a thin rectangular Permalloy platelet along both its long ($y$) and short ($x$) axes.

## 2) Physics Background

As specified in the official [µMAG Standard Problem #1 Problem Statement](https://www.ctcms.nist.gov/~rdm/stdprob_1.html) and [Submission Guidelines](https://www.ctcms.nist.gov/~rdm/sub_guide1.html):

### Geometry

The sample is a rectangular Permalloy platelet of dimensions:
- $L_x = 1.0\,\mu\text{m} = 1000\,\text{nm}$ (short in-plane axis)
- $L_y = 2.0\,\mu\text{m} = 2000\,\text{nm}$ (long in-plane axis)
- $L_z = 20\,\text{nm}$ (thickness)

### Material Parameters

- Exchange stiffness: $A = 1.3 \times 10^{-11}\,\text{J/m}$
- Saturation magnetization: $M_s = 8.0 \times 10^5\,\text{A/m}$ ($J_s = \mu_0 M_s = 1.005309649\,\text{T}$)
- Uniaxial magnetocrystalline anisotropy: $K_1 = 5.0 \times 10^2\,\text{J/m}^3$, with the easy axis parallel to the long ($y$) edge of the rectangle ($\theta = \pi/2$, $\phi = \pi/2$).

These parameters are stored in `permalloy.krn`:

```text
# theta (rad)      phi (rad)        K1(J/m3)   not used   Js (T)        A (J/m)
1.57079632679490   1.57079632679490 5.0e2      0.0        1.005309649   1.3e-11
```

### Field Protocol

Complete hysteresis loops are computed between $\mu_0 H_{\text{ext}} = +50\,\text{mT}$ and $-50\,\text{mT}$ (and back to $+50\,\text{mT}$) for two field orientations rotated $1^\circ$ counterclockwise off the nominal axes to break artificial numerical symmetry:
1. **Long-axis ($y$) loop (`permalloy_long.p2`)**: $\hat{\mathbf{h}} = (-\sin 1^\circ, \cos 1^\circ, 0) = (-0.0174524, 0.9998477, 0)$.
2. **Short-axis ($x$) loop (`permalloy_short.p2`)**: $\hat{\mathbf{h}} = (\cos 1^\circ, \sin 1^\circ, 0) = (0.9998477, 0.0174524, 0)$.

## 3) How to Run the Example in Tommos

### Generate or Regenerate the Mesh

A base grid mesh `permalloy.npz` ($1000 \times 2000 \times 20\,\text{nm}^3$) is included in `examples/standard_problem_1/` (and is automatically generated by `sp1_workflow.py` if missing). To generate a custom resolution mesh manually:

```bash
cd examples/standard_problem_1
pixi run tommos mesh --geom box --extent 1000,2000,20 --h 25.0 --backend grid --out-name permalloy
```

### Run the Workflow (`sp1_workflow.py`)

From the `tommos` repository root:

```bash
# Run both long-axis and short-axis full hysteresis loops:
pixi run python examples/standard_problem_1/sp1_workflow.py

# Run only the long-axis or short-axis loop:
pixi run python examples/standard_problem_1/sp1_workflow.py --case long
pixi run python examples/standard_problem_1/sp1_workflow.py --case short

# Fast test with a coarser field step (e.g. 25 mT steps) on the descending branch:
pixi run python examples/standard_problem_1/sp1_workflow.py --hstep 0.025 --descending-only
```

## 4) Options & Output

### CLI Options for `sp1_workflow.py`

| Flag | Description | Default |
| :--- | :--- | :--- |
| `--case {both,long,short}` | Which loop(s) to run (`long`, `short`, or `both`). | `both` |
| `--h <float>` | Mesh element size in nm when generating `permalloy.npz`. | `50.0` |
| `--regenerate-mesh` | Force regeneration of `permalloy.npz` via `tommos mesh`. | Off |
| `--hstep <float>` | Override field step magnitude in Tesla. | `0.001` (from `.p2`) |
| `--descending-only` | Run only $+50\,\text{mT} \to -50\,\text{mT}$ (`loop = False`). | Off |
| `--write-vtu` | Save VTU magnetization snapshots at each field step. | Off |
| `--loop-arg <arg>` | Forward extra CLI arguments to `tommos loop` (repeatable). | None |
| `--workdir <path>` | Output directory for run folders and summary plot. | `examples/standard_problem_1/runs` |
| `--png <filename>` | Output plot filename inside `--workdir`. | `sp1_hysteresis.png` |

### Output Files

Inside `examples/standard_problem_1/runs/` (or `--workdir`):
- `sp1_hysteresis.png` — Combined hysteresis plot of $m_y(\mu_0 H_{\text{ext}})$ (long axis) and $m_x(\mu_0 H_{\text{ext}})$ (short axis).
- `long_axis/permalloy.mh`, `hysteresis.csv`, `mammos_hysteresis.csv` — Long-axis simulation data.
- `short_axis/permalloy.mh`, `hysteresis.csv`, `mammos_hysteresis.csv` — Short-axis simulation data.
- Console summary table of remanent magnetization $M_{\text{rem}}/M_s$ and coercive field $\mu_0 H_c$ [mT].
